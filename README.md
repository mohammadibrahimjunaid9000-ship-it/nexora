# Nexora — The Future of AI-Driven Learning

Nexora is a futuristic, modular platform designed for creators to teach and learners to master skills through interactive playlists, live webinar sessions, gamified points, and AI-driven collaboration networking.

## How to Run

1. Navigate to the backend directory or run from the repository root:
   ```bash
   python backend/app.py
   ```
2. Open your browser at `http://127.0.0.1:5000/`.
